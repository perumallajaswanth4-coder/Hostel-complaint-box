# AI Technology Website

A responsive landing page concept for a human-centered AI technology platform, built with HTML and CSS.

## Run locally
Open `index.html` in a modern browser. Keep `style.css` beside it.

## Deploy with GitHub Pages
Open repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. The project is in the `ai-technology-website` folder; for a project-root deployment, publish that folder through an appropriate Pages workflow or move its files to the repository root after backing up existing content.

## Customize
This is a front-end concept. Replace the fictional company, team profiles, contact email, and demo claims before presenting it as a real organization.
